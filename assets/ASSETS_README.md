# Atlas Géographique - Instructions pour les assets

## Images requises

### Image de bienvenue (Globe terrestre)
Placez l'image du globe terrestre fournie dans :
`assets/images/globe.jpg`

### Drapeaux des pays
Placez les images des drapeaux dans le dossier `assets/flags/` avec les noms suivants :

1. `france.png` - Drapeau de la France
2. `tunisia.png` - Drapeau de la Tunisie
3. `brazil.png` - Drapeau du Brésil
4. `italy.png` - Drapeau de l'Italie
5. `canada.png` - Drapeau du Canada
6. `australia.png` - Drapeau de l'Australie
7. `germany.png` - Drapeau de l'Allemagne
8. `spain.png` - Drapeau de l'Espagne
9. `south_africa.png` - Drapeau de l'Afrique du Sud

## Téléchargement des drapeaux

Vous pouvez télécharger les drapeaux depuis : https://www.countryflags.com/

## Structure des dossiers

```
assets/
├── images/
│   └── globe.jpg
└── flags/
    ├── france.png
    ├── tunisia.png
    ├── brazil.png
    ├── italy.png
    ├── canada.png
    ├── australia.png
    ├── germany.png
    ├── spain.png
    └── south_africa.png
```
